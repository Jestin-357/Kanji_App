# Kanji Learning Website

A standalone React + Vite website built from your Kanji app.

## Run locally
```
npm install
npm run dev
```

## Build for production
```
npm run build
```
This creates a `dist/` folder — deploy that folder to any static host.

## Deploy for free
See the step-by-step guide provided in chat for deploying to Netlify or Vercel.
